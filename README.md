# 먹빛설화 — v4 / Codex가 직접 제작

**헤르메스를 거치지 않습니다.** 코덱스가 원화·Flow·내레이션·음악·자막·최종 편집과 검수까지 수행하도록 지침을 다시 구성했습니다.

## 시작

**[START_CODEX.md의 명령 하나를 Codex에 전달](START_CODEX.md)**하세요. 기본 대상은 해와 달1부입니다. `prepare`로 프롬프트만 만든 뒤 끝내는 것이 아니라, 실제 도구로 자산 생성과 두 언어 최종 렌더까지 이어가도록 지시합니다. 도구·로그인·추가과금이 막혔을 때만 정확한 차단 상태를 보고합니다.

## 달라진 완성 구조

| 구간 | 원본/방법 | 시간 |

원화9장, 본문영상7개입니다. 오프닝과 예고에 Flow를 추가 사용하지 않습니다. 실제720p·4초·x1·7크레딧 조건에서 신규7개는49크레딧 예상/최대50입니다. 이미지·TTS·음원은 별도 추가비용 여부를 확인합니다. 기존 원본이 있으면 먼저 재사용하며 무조건49를 다시 쓰지 않습니다. 생성 품질이 첫시도에 보장된다는 의미는 아닙니다.

## 이번 결과물을 보고 고친 것

두 첨부영상은28초/1080×1920/30fps였지만, 화면 아래쪽의 작은 자막과 검은덩어리·다각형·밝은 전면가림막이 장면 감상을 방해했습니다. v4는 제목/자막의 실제 픽셀값과 줄바꿈·위치·노출시간을 고정하고, 모든 경계를 가리던 전환을 없앴습니다. 이전 지침의 과도한 전환 요구도 수정한 것입니다. [실제 영상 검토와 측정 한계](docs/VIDEO_AUDIT_V4.md)

자막KO72px/EN68px, 제목KO108px/EN92px, 자막최소64px. 단어별 점멸 대신1~2줄 문장으로 표시합니다. 대부분 기본컷, 일부8프레임 디졸브만 사용합니다. 밝은 화면 덮기/검은먹덩어리/삼각형/속도램프는 금지했습니다. 첫 대상은 더 짧은 KO/EN 원고와 각 컷의 목표 호흡·줄바꿈까지 작성했습니다.

## 로컬 보조도구

```sh
python tools/codex_production.py check
python -m unittest discover -s tests -p 'test_codex_production.py' -v
python tools/codex_production.py prepare --episode 01_sun_and_moon_p01 --out runs/01_sun_and_moon_p01/v4_take01
```

이 도구는 계획·프롬프트·검수 파일을 만들 뿐 이미지/Flow/TTS를 호출하지 않습니다. Codex는 그 뒤 **실제 연결된 도구를 사용해 제작을 계속**해야 합니다. 같은 출력폴더가 있으면 덮어쓰지 않습니다. 기존 YouTube 제목·설명·태그를 읽어 실행용33초 문구도 준비합니다.

## 완료 상태의 구분

현재 GitHub 패키지는 지침·JSON·보조도구이며 **새 이미지·Flow 영상·TTS·최종MP4는 아직 만들지 않았습니다.** 로컬 규격/원고/실패상태 테스트22개를 실행해 통과했습니다. 첫 대상 prepare의9개이미지프롬프트/7개모션프롬프트/990프레임은 확인했지만 실제 Flow UI 자동조작과 TTS/음악/최종렌더의 end-to-end 테스트는 하지 않았습니다.

무료로컬 수정과 사전검수로 실패가능성을 줄이는 설계입니다. 생성모델 결과·음성 자연스러움·인증된도구 가용성을 문서만으로 보장하지 않습니다. 이전자료는 Git 이력과 archive/v3/snapshot에 보존하며, 사용자PC의 기존 결과물은 삭제하지 않습니다. 유튜브 게시/예약과2부 자동제작은 실행하지 않습니다.
