## 비용을 먼저 확인하세요

2026-09-17 확인한 Google 공식 안내에서 **Gemini Omni Flash 720p·4초·출력 1개는 7크레딧**입니다. 편당 최초 생성 7회는 49크레딧이며 **재생성 여유는 1크레딧뿐**입니다. 50크레딧은 5편 전체가 아니라 **한 편의 한도**입니다. 5편 최초 생성 합계는 245크레딧이므로, 다섯 편을 한 번에 자동 생성하지 않습니다.

실제 계정의 모델·해상도·길이·출력 개수·예상 차감액을 매번 확인합니다. 가격이나 사용 가능 기능이 다르면 제출하지 않습니다. 자동 재시도·유료 업스케일·40크레딧 영상 편집 기능을 사용하지 않습니다. 이미지 준비와 TTS에 별도 결제가 필요하면 결제 없이 준비 단계에서 멈춥니다.

공식 확인: [Flow 크레딧 안내](https://support.google.com/flow/answer/16526234), [지원 모델과 기능](https://support.google.com/flow/answer/16352836?hl=en). 계정별 실제 표시를 우선합니다.

## 편집의 핵심

그림을 확대하는 슬라이드쇼가 아니라 **인물의 작은 행동·옷자락·물결·눈발이 실제로 움직이는 7개의 영상**을 사용합니다. 복잡한 신체 변신은 요구하지 않고 실루엣, 화면을 가리는 먹, 후반 합성으로 표현합니다.

완성 길이는 30fps 기준 **840프레임**입니다. 전환을 겹쳐 28초가 짧아지지 않도록 각 컷의 120프레임을 유지하고 경계 위에 가림막 효과를 합성합니다. 구현 규격은 [수묵 전환·애니메이션 사전](docs/INK_EDITING_SPEC.md)을 따릅니다.
