# 먹빛설화 — Inkbound Tales

## v2: 대사 없이, 영상 한 벌로 한국어판과 영어판

**편당 Flow 7컷 × 4초 = 28초. 같은 영상으로 KO + EN 두 파일을 제작합니다.**

```text
이미지 7장 → Flow 공용 영상 7개 → 무음·무자막 28초 마스터 1개
                                  ├ 한국어 내레이션 + 한국어 자막 → *_ko.mp4
                                  └ 영어 내레이션 + 영어 자막    → *_en.mp4
```

등장인물 대사·인용 연기·립싱크는 없습니다. 언어별 한 명의 화면 밖 내레이터가 처음부터 끝까지 이야기를 들려줍니다. 그림 속 인물은 말하지 않습니다. 화풍은 한지 질감, 먹 번짐, 옅은 담채가 살아 있는 몽환적인 한국풍 수묵화입니다.

## 비용: 언어가 두 개여도 Flow 영상 생성은 한 번

2026-09-17 Google 공식 비용표의 Gemini Omni Flash 720p/4초/출력 1개 = 7크레딧 기준입니다. 실제 계정 UI를 매번 확인합니다.

| 작업 | Flow 생성 수 | 예상 Flow 크레딧 |
|---|---:|---:|
| 한 이야기의 언어 공용 영상 | 7 | 49 |
| 동일 마스터에 한국어 음성/자막 로컬 합성 | 0 | 0 추가 |
| 동일 마스터에 영어 음성/자막 로컬 합성 | 0 | 0 추가 |
| 한 이야기 / 완성본 2개 합계 | 7 | 49 |

남는 1크레딧으로 동일 설정의 재시도는 불가능합니다. 양품 7개를 보장하는 견적이 아니며 자동 재생성은 금지합니다. 이미지 7장과 언어별 TTS는 **추가 비용 없이 준비할 수 있다는 조건**이 별도 필요합니다. TTS 제공자 요금, 이미지 비용, 음악 라이선스 비용을 49에 포함됐다고 설명하지 않습니다. 영어 번역/음성은 Flow가 아닌 로컬 편집 단계에서 처리합니다.

5편 모두 만들면 35개 Flow 원본 / 245크레딧 예상 / 최종 10개 언어별 영상입니다. 한 번의 요청으로 다섯 편을 자동 실행하지 않습니다.

공식 안내: https://support.google.com/flow/answer/16526234?hl=en
