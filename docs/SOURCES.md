# 출처와 각색 범위

확인일: 2026-09-17. 아래 자료는 설화 줄거리와 도구 기능을 확인하기 위한 것이다. 현대 삽화·영상·음악·번역문을 그대로 가져오는 지시가 아니다. 장면 구성, 내레이션, 캐릭터와 편집 규격은 이 저장소를 위한 새 각색/창작이다.

## 이야기

### 01 해와 달이 된 오누이
- 한국학중앙연구원, 한국민족문화대백과사전, 「해와 달이 된 오누이」.
- https://encykorea.aks.ac.kr/Article/E0062663
- 확인한 요소: 호랑이의 위협, 나무로 피신하는 남매, 하늘에서 내려오는 동아줄, 해와 달이 되는 결말.
- 이번 각색: 어머니와 호랑이의 산길 대결 및 잔혹한 죽음은 생략하고 집 앞 위협부터 시작. 해/달이 어느 남매인지는 고정하지 않음. 28초용 축약이며 전승 전체의 유일한 정본으로 소개하지 않음.

### 02 선녀와 나무꾼 — 돌아간 날개
- 한국학중앙연구원, 한국민족문화대백과사전, 「나무꾼과 선녀」.
- https://encykorea.aks.ac.kr/Article/E0011342
- 확인한 요소: 감춘 날개옷, 지상의 생활, 날개옷을 되찾은 선녀와 아이들의 승천. 후일담은 여러 유형으로 전승.
- 이번 각색: 사슴의 보은과 나무꾼의 천상 방문/수탉 후일담은 생략. 선녀의 귀환 관점에 집중하고 전 컷 옷을 입힌다. 마지막 문장은 이 작품의 해석이지 원전 인용이 아니다.

### 04 도깨비방망이 — 개암 한 알
- 한국학중앙연구원, 한국민족문화대백과사전, 「도깨비방망이 설화」.
- https://encykorea.aks.ac.kr/Article/E0015530
- 확인한 요소: 부모를 먼저 생각하며 개암을 챙긴 사람, 빈집의 도깨비, 개암 깨무는 소리에 도망간 도깨비, 남겨진 방망이, 따라 한 욕심쟁이의 실패.
- 이번 각색: 욕심쟁이가 맞는 장면은 보여주지 않고 빈손 결말로 축약. 도깨비의 먹 실루엣은 이 작품만의 디자인.

### 03 구미호의 마지막 밤 / 05 매화령
- 전승 작품의 정확한 재현이 아니라 이번 프로젝트에서 만든 한국풍 창작 설화.
- 03의 구슬/천 년/아이를 위한 희생이라는 구체 규칙과 05의 약속/묘표/매화 재회 줄거리는 창작 설정이다.
- 영상 설명과 첫 컷의 작은 분류 표시에 `한국풍 창작 설화`라고 쓴다. 실제 전설이 채록된 장소·원전·역사 기록을 만들어 붙이지 않는다.

## 제작 기술

### Flow 비용
- Google Flow Help, Manage your Google Flow credits.
- https://support.google.com/flow/answer/16526234
- 확인한 표: Omni Flash 720p 4초 7크레딧/생성, 360p 4초 4크레딧, 영상 편집 40크레딧. 비용은 요청 수가 아니라 생성 결과 수에 적용될 수 있음.
- 이 저장소는 720p 4초 결과 1개씩 7회, 예상 49크레딧을 사용한다. 50으로 항상 7개 양품이 확보된다는 뜻은 아니다. 가격과 접근 가능 여부는 실제 계정 UI에서 재확인한다.

### Flow 기능
- Google Flow Help, Learn about Google Flow models & supported features.
- https://support.google.com/flow/answer/16352836?hl=en
- 확인한 기능: Omni Flash의 세로/가로, 첫 프레임 기반 영상 생성, 4초 길이. 이 프로젝트는 지원되는 기능 중 시작 이미지 한 장을 쓰는 방식을 선택했다.
- 브라우저 자동화/전용 API/MCP가 사용자 환경에 구성됐다는 근거는 이 문서에 없다. 실제 연동 확인이 필요하다.

### Remotion
- 공식 transitions 문서: https://www.remotion.dev/docs/transitions
- 일반 Sequence 문서: https://www.remotion.dev/docs/sequence
- 결정론적 애니메이션과 렌더 방식은 설치된 공식 스킬/문서 및 패키지 버전을 확인한다.
- 이 프로젝트는 총 길이 840프레임을 보존하기 위해 컷 위 오버레이를 사용하는 설계다. 특정 버전의 Overlay API 존재를 전제하지 않는다.

## 사용 기록

이미지·음악·효과음을 실제 확보할 때 별도 asset_sources.csv에 파일명/제작 도구/직접 제작 여부/출처/이용 조건/확인 날짜를 기록한다. 서비스가 붙인 표시를 지우지 않는다. 법률상 권리 전체가 자동 해결되었다고 주장하지 않는다.
