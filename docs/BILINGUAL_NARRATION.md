# 내레이션 전용 KO/EN — v3 파트별 적용

하나의 episode_id에 공용4초 영상7개, 한국어·영어 완성본 각1개다. 언어별 외부 내레이터 한 명만 말하고 등장인물 대사·직접 인용·역할극·립싱크는 사용하지 않는다. 기도·약속·생각도 간접 서술한다. 개암 소리는 효과음이며 내레이터가 의성어를 연기하지 않는다.

## 원고와 발화량

narration/manifest.json의 episodes가 활성 목록이다. narration/<episode_id>.ko.txt와 .en.txt를 각각 한 연속 입력으로 읽는다. 7줄은 의미 구간이지7회 TTS나4초 고정 자막이 아니다. 제목·파트번호·분류는 낭독하지 않는다. 이전01/02/04 단일편 원고는 아카이브로 보관하며 새 파트에 사용하지 않는다. 03/05는 기존 원고를 유지한다.

새6파트는 그림을 볼 여유를 위해 영어42~45단어로 작성했다. 이 분량은 발화시간 보장이 아니다. 실발화 약20~23초와 나머지 호흡·행동·음악을 목표로 실제 음성의 길이·호흡·발음·의미 구간을 측정하고 듣는다. 빠르게 읽어야만 맞으면 원고를 줄인다. 기존 단편의 분량도 실제 청취로 확인한다.

## 각 음성에서 별도로 정렬

언어별 연속 음성 생성 → 실제 길이와 청취 확인 → 문장·단어 정렬 → 같은7컷의 사건과 대조 순서로 진행한다. 한국어 자막 타임코드를 영어에 그대로 복사하지 않는다. 4초마다 기계적으로 쉬거나 컷마다 화자를 바꾸지 않는다. 마지막 말은27.2초 이전, 마지막 약0.8초 이상은 여운을 남기도록 실제 파일로 검수한다.

영어는 같은 원인·인물·소품·결말을 자연스러운 어순으로 전달한다. 새로운 사건을 추가하지 않는다. 단어 강조와 ducking은 해당 음성에 맞추되 영상·전환·SFX 사건 시점은 두 언어가 공유한다. 길면 원고를 간결하게 고치고 연속 음성을 다시 만든다. 영상 연장, 추가 클립,1.08배 초과 가속, 음절 잘라 붙이기는 하지 않는다. 무덤·끊어진 줄 같은 반전은 그림 공개 전에 발화나 통문장 자막으로 누설하지 않는다.

## 화면 표시와 목소리

공용 마스터는 무음·무제목·무자막이다. 한국어판에는 한국어 음성·자막·제목·부번호, 영어판에는 영어와 Part번호를 붙인다. 두 언어 동시 자막이 아니다. 분류는 각색의 경우 `전래설화 각색 / Retold Korean Folktale`, 창작 단편의 경우 `한국풍 창작 설화 / Original Korean-Inspired Tale`이다. 첫 컷의 작은 오버레이로 표시할 수 있지만 독립 타이틀 컷은 추가하지 않는다.

선녀는 sky maiden, 구미호는 fox spirit, 도깨비는 goblin을 짧은 영어 설명어로 사용한다. 이는 이 작품의 현지화 선택이지 유일한 학술 번역은 아니다. 영상은 한국풍을 그대로 유지하며 서양 요정이나 오크로 바꾸지 않는다. 매화는 plum blossom, 개암은 hazelnut으로 구분한다.

각 언어에서 자연스러운 기존 음성을 사용한다. 두 언어가 같은 voice_id일 필요는 없으며 음성 복제나 별도 유료 더빙 가입을 요구하지 않는다. 무료 또는 기존 구독 포함 여부를 확인하고 추가 과금이면 호출 전에 멈춘다. TTS 실패를 Flow 재생성으로 해결하지 않는다.

## QA와 비용

한 파트의 KO+EN 합산 Flow 비용은 최초49 예상, 최대50이다. 두 파트 전체 비용과 혼동하지 않는다. 원본·마스터 해시,840프레임, 언어별 실제 첫·마지막 발화, 자막 가독성, 사건 싱크, 대사 없음과 실제 청취·시청 방법을 기록한다.

한 언어만 완성되면 PARTIAL_LOCALIZATION이다. 기술 검사만으로 음성이 자연스럽다고 판정하지 않는다. 미디어를 생성하지 않은 현재 원고의 상태는 BRIEFS_READY다.
