# 시리즈 패키징 — v4 / series-packaging-1

## 적용 범위와 근거

사용자가 제공한 古卷残灯 계정의 두 스크린샷에서 관찰한 **포스터형 표지, 짧은 작품명, 통일된 피드, 한 장면의 강한 단서**를 한국 설화의 제작 규칙으로 번역한다. 이 문서는 그 계정의 원본 영상을 프레임별로 시청한 보고서가 아니다. 실제 컷 수·제작 도구·음성 방식·평균 시청 지속시간을 확인했다고 쓰지 않는다. 좋아요는 조회수가 아니며, 게시일과 노출 조건이 다른 작품의 숫자로 특정 성별·괴담 소재가 성공 원인이라고 단정하지 않는다. 성장률·조회수 상승도 보장하지 않는다.

다른 제작자의 원화·인물·글자·로고·구도를 복제하지 않는다. 기존 여덟 편의 순서와 전래/창작 구분을 유지한다. 선정적인 여성형 괴담이나 잔혹 장면을 늘리는 변경이 아니다. 한국 복식·초가·창호·민화적 호랑이·한지·수묵담채가 정체성이다.

## 실행 우선순위

기술 규격은 기존 `production/director_v4.json` 그대로다. **Codex 직접 제작, 오프닝2초+본문7×4초+마지막3초=33초/990프레임, 원화9장, Flow7개, KO/EN 공용 시각 마스터**를 유지한다. 실제 계정 조건 확인 후 신규 본문7개 예상49/한도50이며 추가 현금결제 승인한도는0이다.

`production/series_packaging_v4.json`은 `catalog_v4.json`의 **표지 제목·오프닝 구도·편별 시각적 초점**에 적용하는 최신 오버레이다. 기존 상세 JSON/episode/story의 사건·인물·모션·원고를 대체하지 않는다. `tools/codex_production.py check`와 `prepare`가 자동으로 읽으므로 별도 명령을 기억할 필요가 없다. 렌더할 때는 옛 카탈로그만 따로 읽지 말고 **해당 run의 `run_plan.json.cards`와 `packaging/brief.json`의 합쳐진 값**을 사용한다.

해와 달2부는 `production/01_sun_and_moon_p02_v4.json`을 명시적으로 연결한다. 이전 카탈로그에 이 연결이 없어 구형 본문으로 되돌아가던 경로를 바로잡는다. 2부 상세안에 맞춰 오프닝→01은 cut, 가지→기도와 줄이 끊어진 뒤→천체는 짧은 dissolve로 정렬한다. 33초 슬롯은 줄이지 않는다.

## 표지·첫 프레임·채널 통일

표지는 `images/00_opening.png`를 그대로 재사용하여 언어별 글자만 로컬 합성한다. 계획상 출력은 `packaging/cover_ko.png`, `packaging/cover_en.png`다. **열 번째 원화나 여덟 번째 Flow 클립이 아니다.** prepare는 PNG를 만드는 도구가 아니며 표지 합성은 실제 편집 단계에서 수행한다. 업로드 가능 방식은 플랫폼의 실제 UI에서 확인하고, 파일이 생겼다고 게시하지 않는다.

첫 프레임부터 완성 원화와 이야기의 단서가 보인다. 빈 로고, 검은 도입, 자막 설명을 기다려야 이해되는 그림은 피한다. 오프닝은 기존 2초이며 음성 없이 환경음/음악과 작은 로컬 움직임만 사용한다. 제목 등장 시점·크기·행간은 v4 디자인 기준을 유지한다.

한 장은 **하나의 중심 대상 또는 응집된 인물군 + 핵심 단서 하나**로 구성한다. 모든 표지를 인물 클로즈업으로 만들지 않는다. 문, 줄, 빈자리, 구슬, 개암, 발자국처럼 이야기마다 다른 소품을 중심으로 삼는다. 큰 명암 덩어리와 여백은 통일하되 안개산수·똑같은 포즈·같은 붉은 조명을 반복하지 않는다. 강조색은 이미 승인된 옥빛·리본·매화·황토빛을 활용하며 기존 인물 색을 재배정하지 않는다.

제목은 KO108px/EN92px, 최대2줄. 그림에 글자를 생성시키지 않는다. 1080×1920 원본, 360×640 모바일 미리보기, 180×320 작은 썸네일 크기에서 실제 글꼴과 원화로 검수한다. 이 크기는 자체 검수용이지 플랫폼 의무 규격이 아니다. 글자와 얼굴·핵심 단서가 겹치거나, 축소하면 호랑이가 검은 점으로만 보이면 구도를 점검한다. 승인 원화를 바꾸기 전 로컬 크롭·글자 위치 조정을 우선하되 서비스 표시나 중요 소품을 자르지 않는다.

## 7컷의 인과와 감정

각 편의 `shot_focus`는 7개이며 실제 이미지 프롬프트에 **구도 우선순위**로 붙는다. 원래 장면과 승인 인물/소품이 우선하고 새로운 사건을 한 컷에 더 넣지 않는다. Flow 모션 프롬프트와 기존 내레이션은 그대로 유지한다. 해와 달2부만 이미 작성된 v4 상세 원고/모션을 올바르게 불러온다.

후킹은 큰 소리·공포 얼굴·배속이 아니라 **정체, 부재, 선택, 반복과 차이**로 만든다. 선녀의 귀향을 배신으로 몰거나 옷을 훔친 일을 낭만화하지 않는다. 어린이 위협은 기존 비폭력 묘사 범위 안에서 다룬다. 구미호와 매화령의 창작 표시는 유지한다. 결말의 반전을 오프닝 표지에 미리 노출하지 않는다.

대부분의 전환은 cut, 기존 허용된 짧은 dissolve만 사용한다. 단어 점멸·가라오케·먹덩어리·전면 가림막·속도 램프는 추가하지 않는다. 표지 문법을 가져온다고 타 계정의 영상 길이나 편집 속도를 추측해 이식하지 않는다.

## 기존 자산과 재개

이 변경은 **기존 승인 이미지·Flow·WAV를 다시 생성하라는 명령이 아니다.** 기존 run과 사용자 미커밋 변경을 보존한다. 먼저 클린 원본을 확인하고 쓸 수 있는 파일을 재사용한다. 새 표지 제목은 글자 합성만 바꿀 수 있다. 구도 변경이 새 유료 생성을 요구하면 자동 실행하지 않는다. 새 run을 만든다고 기존 episode 지출 원장이 초기화되지 않는다.

해와 달2부는 1부의 승인 이미지와 `part_01_end.json` 등 연속성 기록을 우선한다. 오빠/동생의 나이·옷·리본, 호랑이 줄무늬, 나무 방향, 달 위치, 바람을 유지한다. 새 패키징 메모가 승인된 외형을 바꿀 권한은 없다.

## 실행 결과와 검수 증거

기존 prepare 결과에 다음 계획 파일만 추가된다.

- `packaging/brief.json`: 합쳐진 카드, 언어별 제목, 원화 재사용 경로, 7컷 초점, 기존 원고, 글자 규격.
- `packaging/REVIEW.md`: 첫 장면·모티프·결말·연속성 검수표.
- `evidence/packaging_review.json`: 모든 항목 PENDING, evidence=null로 시작. 실제 미리보기와 판단 근거 없이는 PASS로 바꾸지 않는다.

실행용 `youtube/{ko,en}/title.txt`에도 새 제목이 반영되며 옛 제목은 metadata_draft의 `source_title`에 남긴다. 기존 `youtube/metadata.json`은 수정하거나 게시하지 않는다. 원전/창작 설명, 태그, 출처 문구를 보존하고 기존처럼 33초용 설명을 내보낸다.

```sh
python tools/codex_production.py check
python -m unittest discover -s tests -p 'test_series_packaging.py' -v
python -m unittest discover -s tests -p 'test_codex_production.py' -v
python tools/codex_production.py prepare --episode 01_sun_and_moon_p02 --out runs/01_sun_and_moon_p02/v4_packaging_take01
```

마지막 명령의 경로는 새 폴더 예시다. 같은 경로가 있으면 덮어쓰지 않는다. 실제 제작 요청은 기존 `START_CODEX_EPISODES.md`에서 선택한 편 하나만 실행한다.

## 이번 변경의 검증 범위

새 `test_series_packaging.py` **22개 테스트를 로컬에서 실행하여 통과**했다. 실제 8편 패키징 JSON과 명시적인 합성 소스/미디어 입력으로 오버레이, 8편 prepare, 9/7개 프롬프트, 990프레임, 예산 불변, 2부 상세안 연결, 한영 제목/예고 동기화, 기존 원고/모션 보존, 덮어쓰기 거부, 미생성·검수대기 표시를 확인했다. 기존 `test_codex_production.py`는 보존하며 이번 환경에서는 전체 저장소 소스 기반 suite를 재실행하지 않았다. 변경한 기존 제작 도구는 수정 부분을 되돌린 로컬 복사본의 Git blob SHA가 원본과 같은지도 확인했다.

새 이미지·표지PNG·Flow·TTS·음원·MP4는 이번 문서/도구 수정에서 생성하지 않았다. 실제 원화 가독성·음성 청취·미디어 end-to-end 검수·시청 성과는 아직 확인하지 않았다.
