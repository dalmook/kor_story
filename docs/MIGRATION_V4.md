# v3 → v4 충돌 방지

| 옛 지시 | 현재 지시 |
|---|---|
| Hermes가 감독, Codex가하위편집 | Codex가직접전체실행 |
| 최종28초/840프레임 | 본문28초/840,최종33초/990 |
| 오프닝/별도예고카드금지 | 오프닝2초+마지막원화3초필수 |
| 모든경계에전면먹/천/안개가림 | cut와짧은dissolve만,전면색가림금지 |
| 원화7장 | 카드포함9장,Flow본문7개는유지 |
| 작은자막/단어별교체허용여지 | 원본KO72/EN68px,문장1~2줄고정 |
| 원고를빠르게읽혀슬롯에맞춤 | 짧은원고/실제정렬/자연스러운쉼,배속없음 |
| 음악이없으면그냥무BGM납품 | 적법한BGM준비필수,없으면미완성상태명시 |

기존8개episode_id와파트분할은유지한다. 원본 `episodes/`와 `stories/`는본문의사건/캐릭터/이미지/모션내용을참조한다. 그문서의옛전환표나최종시간이새JSON을덮어쓰면안된다. 해와달1부는v4상세JSON이원고/구도/줄바꿈까지대체한다.

기존 `narration/manifest.json`과검사기는v3본문원고의무결성을검사한다. v4실행은 `production/catalog_v4.json`, `director_v4.json`, 생성된run_plan.json과별도실측정렬파일을사용한다. 옛검사PASS를새33초완성본PASS라고부르지않는다.

기존YouTube제목/태그문구는보존한다. v4의prepare는해당언어설명에서28초/28seconds를33초/33seconds로바꾸어run/youtube/ko·en에내보낸다. 그실행용파일을사용하고옛28초설명을그대로게시하지않는다. 음악크레딧/최종영상변경도그문구에반영한다. 기존youtube_metadata검사기는옛문구JSON정합성만검사하며새렌더를확인하지않는다.

이전시점전체트리는archive/v3/snapshot으로보존한다. 아카이브의AGENTS나Hermes명령은실행하지않는다. 사용자PC의원본/완성본은삭제하지않고새run에교정한다. 동시사용자변경이있으면Git상태를먼저검토하며강제reset/push를하지않는다.
