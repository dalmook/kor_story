# 공통 제작 명령 v3 — 한 파트의 영상1벌 → KO/EN 2개

## 1. 선택과 작업 보호

AGENTS.md, PART_PRODUCTION.md, BILINGUAL_NARRATION.md, INK_EDITING_SPEC.md와 narration/manifest.json을 읽는다. 명시한 episode_id 하나, 해당 brief, 부모 시리즈 문서를 선택한다. 시리즈 이름만 지정되면 p01, 단편은 기존ID를 사용한다. 아카이브와 다음 파트를 자동 실행하지 않는다.

기존 clone, 미커밋 변경, 편집 환경과 이미 생성한 자산을 확인하고 보존한다. 실제 설치된 FFmpeg/Remotion/Codex/TTS/Flow 연동 및 관련 스킬을 읽고 재사용한다. 없는 API나 CLI를 발명하거나 무거운 모델을 새로 설치하지 않는다. 현재 저장소는 제작 명령서이며 완성 미디어나 렌더러가 이미 구현되어 있다는 뜻이 아니다.

## 2. 비용 잠금

실제 UI에서 모델·720p·4초·출력1개·7크레딧·잔액을 확인한다. 이 조건의 최초7개는49크레딧, **선택한 episode의 KO+EN 합산 상한은50**이다. 두 파트는98, 전체8편은392크레딧 예상이다. 조건이 다르면 임의로 모델이나 해상도를 바꾸어 제출하지 않는다.

기존 지출과 미확정 작업은 새 run에도 이어서 계산한다. `확정 차감 + 미확정 예약 + 이번 요청 + 남은 필수 컷 예약 <= 50`을 매번 확인한다. 이미지는 영상49 예약분을 침범하지 않게 사전 확보한다. 이미지나 TTS도 같은 Flow 잔액을 쓰면 합산한다. 별도 유료 음성·음원·렌더 비용이 필요하면 승인 없이 호출하지 않는다. API 키가 있다는 이유로 무료라고 가정하지 않는다.

credits.jsonl에 story_id, episode_id, shot_id, attempt_id, job_id, 실제 모델·설정·잔액·단가·차감·예약·환불 상태를 기록한다. 예상49를 실지출로 쓰지 않는다. 브라우저 타임아웃은 중복 제출의 근거가 아니다. 출력x2, 자동 재시도, 유료 Edit/Extend/Upscale, 추가 결제와 영어판 Flow 더빙은 금지한다. 다음 파트는 별도 실행 요청이 있어야 한다.

## 3. 참조·원고·이미지

시리즈의 캐릭터·소품·팔레트와 이전 파트 끝 상태를 확인한다. 실제 참조가 없으면 PLAN_ONLY 상태에서 준비 가능한 자료부터 완성한다. 이전 파트 영상 전체를 자동 생성하지 않는다.

manifest가 가리키는 episode별 KO/EN TXT를 각각 한 화자의 연속 TTS 입력으로 사용한다. 제목·번호·직접 대사는 읽지 않는다. 새 파트는 실발화20~23초와 여백을 목표로 하되 실제로 듣고 정렬한다. 7줄을7회 TTS로 나누지 않는다. 두 언어가 같은 사건을 같은 영상 구간에 설명해야 한다. 길면 뜻을 유지하며 원고를 줄이고 전체 연속 음성을 다시 만든다. 음절 잘라내기나1.08배 초과 가속은 쓰지 않는다. 추가 과금이나 연동 문제는 NEEDS_AUDIO_INPUT으로 남긴다.

각 시작 이미지는 공통 수묵 화풍, 부모 캐릭터 참조, 해당 IMAGE 지시와 제외 사항을 결합한다. 7장을 먼저 대조해 얼굴·옷·손·소품 소유자·위치·빛을 확정한다. 언어별 이미지를 따로 만들지 않고 제목·자막도 이미지에 넣지 않는다.

## 4. 영상7개

시작 이미지1장에 해당 FLOW 지시와 공통 NO_SPEECH를 적용한다. 내레이션 원고를 Flow에 붙이지 않는다. 단일 주동작과 낮은 강도의 환경 움직임을 요구하고, 다른 장면을 끝 프레임으로 넣는 모핑은 하지 않는다. 원본 음성은 제거하며 화면에 말하는 입이 없는지도 확인한다.

shared/flow/01.mp4~07.mp4 한 세트만 만들고 작업ID와 원본 SHA-256을 저장한다. KO/EN 영상 폴더를 따로 생성하지 않는다. 기존 컷은 호환성 검수 후 재사용한다. 1부 클립을2부 첫4초에 그대로 반복하거나 기존7개를14개 새 원본처럼 세지 않는다.

인물 붕괴와 중심 동작 누락은 실패로 기록한다. 작은 결함은 무료 로컬 가림막·크롭·마스크로 보정할 수 있지만 핵심 사건이나 서비스 표시를 지우지 않는다. 복구 불가이면 FAIL이며 정지 이미지 줌으로 대체하지 않는다. 연동·로그인 부재 시 이미지·프롬프트·수동 생성표를 실제 파일로 마무리하고 NEEDS_FLOW_INPUT으로 보고한다. 인증이나 CAPTCHA를 우회하지 않는다.

## 5. 공용 마스터와 언어 출력

원본 FPS를 실제 확인하여 CFR30으로 정규화한다. 7개 컷을 각각120프레임, 시작0/120/240/360/480/600/720에 배치해 총840프레임을 유지한다. 여섯 경계에 지정된 수묵 오버레이 또는 매치컷을 적용한다. 겹침 전환으로 시간을 줄이지 않는다. 효과는 episode_id 기반 고정 시드로 결정론적으로 만든다.

shared/picture_master.mp4는 무음·무제목·무자막이다. KO/EN render_manifest가 같은 마스터 SHA-256과 원본7개를 참조하도록 한다. 음악·SFX는 이용 허가된 공용 트랙을 사용하고, 음성에 맞춘 ducking만 언어별로 조정할 수 있다. 허가된 음원이 없으면 직접 만든 앰비언스 또는 BGM 없는 버전으로 진행한다.

KO에는 한국어 음성·자막·제목·부번호·분류, EN에는 영어만 합성한다. 각 음성에서 SRT를 별도로 정렬한다. 반전을 장면 공개 전에 통문장 자막으로 먼저 보여주지 않는다. 영어가 길어도 그림이나 전환 시간을 바꾸지 않고 원고·호흡을 조정한다. 출력은1080×1920/H.264/yuv420p/AAC48kHz이며,720p 원본 리사이즈를 네이티브1080p 생성이라고 부르지 않는다.

## 6. Codex CLI 하위 명령

```text
선택 episode_id의 brief, 부모 캐릭터, v3 공통 규격을 읽어.
기존 편집 환경을 재사용하고 누락 자산 검사부터 해.
Flow 호출이나 다른 파트 제작은 하지 마.

7클립을 각각120프레임, 시작0/120/240/360/480/600/720으로 배치해.
원본오디오를 제거하고 지정6개 경계의 수묵효과를 오버레이로 합성해.
840프레임 무음·무문자 picture_master를 한 번만 렌더해.
카메라/마스크/입자/전환 seed는 두 언어에서 동일하게 유지해.

각 언어 연속음성과 실제 정렬 SRT로 *_ko.mp4와 *_en.mp4를 출력해.
등장인물 대사/립싱크 없이 제목·파트번호·분류도 각 언어로 넣어.
영문이 길어도 원본연장·Flow재생성·빠른배속으로 해결하지 마.
28초/30fps/840프레임, 음성여백, 사건/반전시점, 언어누출, 글자잘림,
볼륨, 캐릭터/소품연속성과 실제 master 재사용을 확인해.

원본해시·episode원장·두언어manifest/QA·재실행명령을 남겨.
part_end에 실제 마지막프레임/소품소유자/참조해시를 기록하고
다음파트는 자동실행하지 마. 한언어만 있으면 PARTIAL_LOCALIZATION,
실제청취/시청이 없으면 HUMAN_REVIEW_REQUIRED로 보고해.
```

## 7. 저장과 완료

```text
runs/<episode_id>/<run_id>/
  STATUS.md
  credits.jsonl
  edit_plan.json
  shared/
    images/  flow_prompts/  flow/
    picture_master.mp4
    music_fx.wav
    asset_manifest.json
  ko/
    narration.txt
    narration.wav
    narration.srt
    alignment.json
    render_manifest.json
    qa.json
  en/                         # KO와 같은 파일 구조
  project/
  exports/<episode_id>_ko.mp4
  exports/<episode_id>_en.mp4
  evidence/
  QA.md
```

edit_plan에는 story_id와 episode_id, part_number를 모두 저장한다. 공용 컷·전환·seed와 언어별 음성·자막을 분리한다. series_assets의 part_end는 실제 미디어를 확정한 뒤 갱신한다. 파일이 없을 때 경로나 해시를 지어내지 않는다.

원본7개, 공용 마스터, 두MP4·두WAV·두SRT, 원장, 연속성 기록과 실제 기술·청취·시청 검수 후에만 선택 파트 완료다. 한 파트만 끝났으면 전체2부작은 PARTIAL이다. 미디어 없는 문서 수정 단계는 BRIEFS_READY이며 게시·예약 발행도 실행하지 않는다.
