# 공통 제작 명령 v2 — 공용 영상 1벌 → KO/EN 완성본 2개

## 1. 작업 범위

선택한 이야기 하나. Hermes가 감독/이미지/Flow 운영, Codex CLI가 편집/자막/오디오/검수를 맡는다. AGENTS.md와 BILINGUAL_NARRATION.md, INK_EDITING_SPEC.md, 선택 이야기 문서를 모두 읽는다.

목표: 언어별 1080×1920, 30fps, 840프레임, 28.000초, H.264/yuv420p, AAC 48kHz. 720p 원본을 편집 출력 크기로 리사이즈할 뿐, 네이티브 1080p 생성 또는 AI 업스케일이라고 부르지 않는다.

기존 clone/편집 환경을 먼저 확인하고 미커밋 작업을 보존한다. 없는 파일/설치된 도구를 가정하지 않는다. 관련 설치 스킬을 읽고 기존 FFmpeg/Remotion/이미지/한국어 및 영어 TTS를 재사용한다. 큰 모델은 새로 설치하지 않는다.

## 2. 공용 자산과 두 언어 대본 준비

각 이야기의 컷별 KO/EN 문장과 narration/<story_id>.ko.txt / .en.txt를 대조한다. 파일의 문장을 읽으며 캐릭터 대사·직접 인용·감탄사 연기를 추가하지 않는다. 제목/컷번호/라벨은 낭독하지 않는다.

언어별 한 화자, 하나의 연속 음성으로 생성한다. 영어는 한국어 음성 변조나 단어 단위 TTS 조합이 아니라 독립 영어 내레이터로 자연스럽게 낭독한다. 두 언어가 같은 voice_id일 필요는 없고 서정적/명료한 감독 톤만 맞춘다.

영어 글자 수만 보고 적합 판정을 하지 않는다. 두 음성 모두 길이·호흡·발음을 실제로 확인한 뒤 7개 의미 구간이 공용 영상과 맞는지 검수한다. 늦으면 영상을 늘리지 말고 같은 뜻의 문장을 줄여 다시 낭독한다. TTS 추가 과금이 필요하면 호출 전에 멈추고 대본/설정만 남긴다.

공통 화풍+캐릭터 참조+각 컷 프롬프트로 이미지 7장을 준비한다. 인물/의상/구도/소품/방향/색을 먼저 고정한다. 한국어용/영어용 이미지를 따로 만들지 않는다. 화면 속 글자/타이틀/자막은 없다.

## 3. 비용 잠금

기준(2026-09-17): Gemini Omni Flash 720p, 4초, x1 = 7크레딧. 계정의 실제 표시를 우선한다. 모델/해상도/길이/출력개수/비용이 다르면 자동 제출하지 않는다.

언어 공용 7회 생성은 49크레딧. **같은 이야기의 한국어판과 영어판을 합쳐 최대 50**이다. 언어를 바꿨다는 이유로 원장을 초기화하거나 다시 49를 쓰지 않는다. 7개 이미지를 같은 Flow 잔액으로 만든다면 이미지 비용도 포함하며 49 예약분을 침범하지 않는다. 별도 TTS/음원/API 비용은 별도 원장에 기록하고 승인 없는 추가 결제 금지.

각 컷 제출 전: run/story/shot/attempt/job ID, 설정 스크린샷 또는 확인값, 실제 잔액, 이미 차감한 비용, 미확정 예약비용, 이번 요청비용, 아직 만들지 않은 필수 컷의 예약비용을 기록한다. 이미 차감+미확정 예약+이번 제출+남은 필수 컷 예약이 50을 넘으면 금지. 실제 지출은 실행 전 null이지 예상 49가 아니다.

x2 출력, 자동 재시도, Edit/Extend, 유료 업스케일, 영어 더빙을 위한 Flow 재업로드를 하지 않는다. 웹 Flow와 유료 API를 같은 것으로 취급하지 않는다. 타임아웃 시 작업 기록을 확인하고 무조건 재제출하지 않는다. 실제 반영된 환불만 인정한다.

## 4. Flow는 시각 정보만 생성

이미지 1장 → 그 컷의 4초 영상 1개. 시작/끝 프레임에 서로 다른 장면을 강제로 연결하지 않는다. 한 컷에 한 핵심 행동, 보조 바람/안개 정도. 영문 프롬프트에 KO/EN 내레이션을 붙이지 않는다.

모든 모션 프롬프트 마지막에 공통 NO_SPEECH 지시를 붙인다. 등장인물이 말하거나 노래하거나 내레이션에 입을 맞추면 안 된다. 생성 음성을 끄는 설정이 없다면 조작을 발명하지 말고 원본은 보존, 편집 입력에서 오디오 트랙을 제거한다. 제거 후 시각적 립싱크 흔적도 검수한다.

다운로드한 7개 원본의 SHA-256과 shot_id를 기록한다. 이미 있는 유효한 컷은 재개/현지화에서 재사용한다. 중심 동작 누락 또는 형태 붕괴를 성공 처리하지 않는다. 작은 오류는 추가 과금 없이 크롭/가림막 등으로 보정 가능하나 핵심 사건을 없애지 않는다. 복구 불가능하면 FAIL과 이유를 남긴다. 사진 줌으로 대체 금지.

Flow 연동이 없다면 images/01~07, image_prompts, flow_prompts, 수동 생성표까지 실제로 만들고 NEEDS_FLOW_INPUT으로 보고한다. 인증/CAPTCHA를 우회하거나 API를 지어내지 않는다.

## 5. 공용 시각 마스터 고정

원본 실제 FPS를 확인하여 CFR 30으로 정규화한다. 7×120프레임, 컷 시작 f0/120/240/360/480/600/720. 컷 경계 전환은 오버레이 방식으로 합성하고 길이를 빼지 않는다.

카메라·전환·색·사물 애니메이션을 공용으로 한 번만 결정한다. 고정 시드로 렌더하며 언어별로 입자 난수를 바꾸지 않는다. `shared/picture_master.mp4`는 840프레임, 무음, 무자막, 언어별 타이틀 없음. 두 완성본은 같은 이 파일을 영상 입력으로 사용한다. 원본 7개 해시와 공용 마스터 해시를 양쪽 렌더 기록에서 참조한다.

효과음/BGM은 공용 `shared/music_fx.wav`에 담을 수 있다. 대사/감탄사/울음 연기/호랑이 엄마 목소리는 넣지 않는다. 내레이션 발화가 다른 만큼 ducking만 언어별로 조절할 수 있다. 효과음의 사건 시점은 같은 영상에 고정한다.

edit_plan.json은 shot_id/start_frame/duration_frames/source_sha256/transition/reveal_window를 공용 필드에, 내레이션/자막/voice_id/실제 타임스탬프는 locale 필드에 둔다. locale별 Flow 작업 목록을 만들지 않는다. 이미 실행한 run이 있다면 이전 파일을 덮어쓰지 않고 자산 호환성을 확인한다. v1 컷으로 v2의 바뀐 사건을 표현할 수 없으면 몰래 추가 생성하지 말고 상충 컷과 비용 제약을 보고한다.

## 8. 완료 기준

두 MP4가 존재하고 각각 28초/840프레임이며 KO에는 한국어, EN에는 영어 내레이션/자막만 있다. 영어판도 한국풍 영상 그대로이고 문화 설정을 서양풍으로 바꾸지 않는다. 두 파일 모두 같은 master SHA-256을 참조한다. 실제 지출/미확정 비용/남은 예산, 두 언어 시청·청취 상태, 누락 컷, 보정 내역을 기록한다. 준비 완료와 영상 제작 완료를 구분한다.
