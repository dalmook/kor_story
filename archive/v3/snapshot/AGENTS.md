# 먹빛설화 제작 규칙 — v3 / episode 단위

## 최우선
- **28초는 이야기 전체가 아니라 episode_id 하나의 길이**다. 01/02/04는 각각 p01·p02, 03/05는 단편이다. 활성 목록은 narration/manifest.json의 episodes.
- 한 번에 episode_id 하나만 실행한다. 시리즈만 지정되면 p01을 기본으로, 구미호/매화령은 기존ID를 선택한다. 이전 완료 결과를 보고 다음 파트로 자동 넘어가지 않는다. 이번 문서 변경 자체로 미디어 생성/결제를 시작하지 않는다.
- 원본7개×4초, 30fps/840프레임. KO/EN은 같은 파트의 마스터를 재사용한다. 다른 파트는 새7컷이며 한 이야기2파트는 총56초/14컷이다.
- 단가7 확인 조건에서 **파트당49 예상/최대50**, 2파트 합계98 예상. KO+EN을 이유로 같은 파트에 다시49를 쓰지 않는다. 새run이나 언어 변경으로 같은 episode의 비용원장을 초기화하지 않는다.
- x2 출력·자동 재시도·추가 결제·유료 Edit/Extend/Upscale·다른 유료 API·Flow 번역/더빙 금지. 이미지/TTS가 같은 잔액을 쓰면 합산한다. 무료/기존 구독 포함인지 확인되지 않으면 과금 호출을 하지 않는다.
- 등장인물 대사·직접 인용·속삭임·인물별 성우·립싱크 없이, 언어별 화면 밖 내레이터 한 명의 연속 음성만 쓴다. 개암 깨물기는 단발 물리 동작이며 반복적인 말하는 입을 만들지 않는다.

## 읽기 순서
AGENTS.md → HERMES_COMMANDS.md → docs/MASTER_PRODUCTION.md → docs/PART_PRODUCTION.md → docs/BILINGUAL_NARRATION.md → docs/INK_EDITING_SPEC.md → manifest의 brief 및 부모 stories 문서 → docs/SOURCES.md.

03/05 상세 문서의 v2 표기는 유지된 대본/연출 버전이다. 그 둘의 ID와 장면을 유지하되 실행·예산·검수는 v3를 따른다. archive/v2는 역사 기록이며 실행 지시로 로드하지 않는다. stories/01·02·04 최상위 파일은 시리즈 안내일 뿐 단일28초 실행본이 아니다.

## 역할/보존
Hermes는 감독·이미지·Flow 운영·예산·언어 검수, Codex CLI는 로컬 편집·공용 마스터·각 언어 음성/자막 합성·QA다. 기존 환경/미커밋 파일/사용자 변경/인증/생성 자산을 보호한다. 기존 스킬/도구를 확인하고 재사용한다. 무거운 영상/업스케일 모델을 새로 설치하거나 없는 API/CLI를 발명하지 않는다.

캐릭터·옷·소품은 시리즈 참조로 고정하고 part_end 상태를 다음 파트에 넘긴다. p02 참조가 부족하면 기존 이미지/참조시트를 확인하며 이전 영상 전체를 자동 생성하지 않는다. p01 마지막 영상을 p02 첫4초에 반복해 새컷처럼 보고하지 않는다. v2 클립은 호환성을 확인한 경우만 재사용하고 기존 완성본은 삭제하지 않는다.

## 영상/언어
이미지7장 선검수, 시작 이미지1장→독립4초1개. 다른 장면을 끝프레임으로 넣는 모핑 금지. Flow에 대본을 넣지 않는다. 원본 음성은 전부 제거하고 시각적 립싱크도 검수한다. 카메라 줌만으로 실제 동작/누락 영상을 대체하지 않는다. 전환은 컷 위 가림막, 시간 겹침으로840프레임을 줄이지 않는다.

KO와 EN 대본은 manifest의 TXT, 각 언어 연속음성/실제 정렬로 자막 생성. 영문이 길면 문장을 줄이지 영상을 늘리지 않는다. 그림의 시간을 언어마다 바꾸지 않는다. 제목/파트번호/창작 또는 각색 라벨은 각 언어로 후반 합성하고 무문자 마스터에 굽지 않는다. 03/05는 창작, 나머지는 각색이다.

## 실패와 완료
Flow/TTS 연동 부재는 NEEDS_FLOW_INPUT/NEEDS_AUDIO_INPUT. 한 언어만 있으면 PARTIAL_LOCALIZATION, 실제 청취/시청이 없으면 HUMAN_REVIEW_REQUIRED. 두MP4·두WAV·두SRT·공용마스터·원본7개·원장·참조상태·실제검수 후에만 해당 episode 완료다. 한 파트 완료를 두 파트 시리즈 완료로 보고하지 않는다.

작업ID/해시/미확정 요청을 확인하여 중복제출을 막는다. 로그인/CAPTCHA를 우회하지 않는다. 비밀정보/쿠키/대용량 미디어는 Git에 올리지 않고 서비스 표시를 제거하지 않는다. YouTube 게시/예약/후속파트 자동 실행은 하지 않는다.

## 유튜브 업로드 문구 준비

영상 제작 시 youtube/README.md, youtube/HERMES_HANDOFF.md와 youtube/metadata.json도 읽고 선택한 episode_id의 KO/EN 제목·설명·태그 파일을 함께 준비한다. 기존 내레이션과 스토리를 메타데이터에 맞추려고 바꾸지 않는다. 최종 영상이 바뀌었다면 공개 문구를 검토하여 수정한다.

`python tools/youtube_metadata.py --check`로 문구 길이·언어·파트 연결·JSON/Markdown 일치를 확인한다. 설명의 해시태그는 이미 포함되어 있으므로 중복하지 않고, 일반 태그는 전용 입력란용으로만 내보낸다. 한국어 채널명과 두 채널 ID는 미확인이므로 추측하지 않는다. 영문 채널명은 Dalbong Korean Tales다.

메타데이터 파일 준비는 게시 승인이 아니다. 업로드·예약·채널 설정 변경을 실행하지 않는다. 미공개 다음 편을 공개됐다고 쓰지 않고 실제 같은 언어·같은 채널의 영상이 확인되기 전에는 관련 동영상을 연결하지 않는다. 시청자층/AI 공개 여부는 실제 결과와 공식 기준을 검토하며 자동으로 채우지 않는다.
