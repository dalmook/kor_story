# 헤르메스 최종 전달문 — 내레이션 KO/EN, Flow 공통 7컷

## 기준 버전과 보존 사항

최신 v2 스토리 개편과 10개의 narration/*.txt를 그대로 사용한다. 과거 단일언어 초안으로 되돌리지 않는다. 매화령은 발자국 없는 여인과 늦은 귀환의 반전, 도깨비 편은 첫 방망이를 얻는 한 사건으로 정리된 현재 버전을 유지한다. 공통 수묵 연출·컷별 이미지/모션 프롬프트·전환 지시는 현재 stories와 INK_EDITING_SPEC.md가 기준이다.

대본의 원본은 **narration/<story_id>.ko.txt와 .en.txt**다. 문장을 다시 복사한 별도 JSON 대본은 만들지 않는다. narration/manifest.json은 경로·검수 시점의 Git blob SHA·장면 줄 수를 기록한 목록이며 대본 자체를 대체하지 않는다. source_commit은 검수한 대본 버전을 뜻하고 전체 저장소를 그 과거 커밋으로 되돌리라는 뜻이 아니다.

## 텍스트 검수 결과와 한계

2026-09-17: 최신 v2 한국어/영어 TXT 10개를 읽고 각 7개 장면 문장, 총 70개 줄을 확인했다. 내려받아 재구성한 UTF-8 내용의 Git blob SHA가 GitHub가 반환한 10개 SHA와 모두 일치했다. 검사 도구로 정상 파일, Windows CRLF 변환, 변경된 문장 감지, 누락 파일 감지를 테스트했다.

검사는 읽기 전용이며 Python 표준 라이브러리만 사용한다. 네트워크·TTS·Flow·유료 API 호출은 없다. **내용 무결성 검사일 뿐, 이야기의 문학적 완성도·실제 TTS의 28초 적합성·자연스러운 음성·영상 품질을 자동으로 보증하지 않는다.** 실제 음성/영상은 아직 생성·청취·시청하지 않았다.

향후 대본을 의도적으로 고치면 story의 KO/EN 문장과 TXT를 함께 갱신하고 검토 후 manifest의 해시도 갱신한다. 해시 불일치를 숨기기 위해 자동 덮어쓰기하거나 무조건 기존 문장으로 되돌리지 않는다. Git blob SHA는 원고 내용 식별용이고, 실제 미디어 마스터의 SHA-256은 제작 시 별도로 기록한다.
