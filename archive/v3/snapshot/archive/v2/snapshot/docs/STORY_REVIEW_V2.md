# 5편 스토리와 내레이션 수정 기록 / v2

요청: 캐릭터 대사 없이 내레이션만, 동일 영상으로 한국어와 영어 각 1편, 28초/7컷/Flow 49 예상 유지, 전체 스토리 재미와 인과 재검토.

이 문서는 편집자의 창작 판단이다. 조회수·완주율 상승이 측정됐다는 뜻이 아니다.

## 대사 제거 기준

01의 직접 기도문은 내레이터의 `아이들은 하늘에 빌었다`로, 05의 여인 말은 선비가 약속을 떠올렸다는 간접 서술로 바꿨다. 04의 깨지는 소리를 내레이터에게 연기시키지 않고 실제 SFX만 사용한다. 캐릭터별 voice_id, 말풍선, 립싱크와 Flow 내장 음성은 사용하지 않는다.

## 한국어/영어 대응

총 35개 시각 장면에 KO 35개/EN 35개 서사 문장을 대응시켰다. 언어마다 한 연속 음성으로 읽는다. 영어 초안은 편별 56/61/60/62/55 단어(영어 축약형은 1단어, 대시로 연결된 말은 분리한 기준). 분량은 실제 TTS 검증을 대체하지 않는다.

영어 문장은 문학적 직역보다 같은 사건을 짧고 자연스럽게 전달하도록 새로 작성했다. 언어가 달라져도 동아줄 종류, 아이 수, 구슬의 대가, 도깨비의 오해, 매화령 무덤의 공개 순서는 바뀌지 않는다. 완성본에 따라 다른 줄거리를 만들어 두 번째 Flow 세트를 요구하지 않는다.

## 실행 시 남은 검증

실제 이미지 일관성, Flow 모션 품질, 한국어/영어 발음·호흡·발화 길이, 840프레임 영상, 6개 전환, 언어별 반전 타이밍, 시청자에게 인과가 이해되는지 확인해야 한다. 이 수정 작업에서 실제 이미지/음성/영상 생성이나 시청 테스트를 수행한 것으로 보고하지 않는다.
